# AGENTS.md

Read PLAN.md first — it lists done and remaining milestones.

- `src/app/(store)/` — storefront routes with shared header/footer layout.
- `src/app/admin/` — admin console; sidebar entries in `src/components/admin/nav.ts` (`ready: true` = live).
- `src/lib/types.ts` — domain model. Every product/order line has a `sellerId`; the store itself is the "platform" seller, partner shops are "partner", future vendors "marketplace". Keep this to stay marketplace-ready.
- `src/lib/fixtures.ts` — stub data; `src/lib/catalog.ts` is the only read layer pages use. Swap its bodies for Netlify Database queries.
- Stock badge is derived from source type (`stockBadge()`), never stored.
- Cart/wishlist live in localStorage via `src/components/Providers.tsx`.
- Images: use `cdn()` from `src/lib/image.ts` (Netlify Image CDN). Product photos generated by `scripts/generate-images.mjs`.
- Styling: Tailwind v4 theme tokens in `src/app/globals.css` (paper/ink/forest/clay/marigold). Fonts: Bricolage Grotesque, Instrument Sans, JetBrains Mono.
- Prices in BDT via `formatPrice()`.
